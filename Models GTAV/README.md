# GTA V model assets

This directory is reserved for model files and conversion metadata used by the native RAGE/Plume test scene.

- Keep large source archives out of Git history unless their redistribution is explicitly permitted.
- Do not add GTA V game archives, extracted Rockstar game assets, title updates, proprietary game data, or generated game code.
- For third-party vehicle mods, verify the author's license and permissions before importing or redistributing.
- Preferred interchange format for the test renderer: glTF 2.0 (`.glb` / `.gltf`) with referenced textures.
- GTA mod formats such as `.yft` / `.ytd` require a separate conversion step; they are not loaded directly by the test renderer.
